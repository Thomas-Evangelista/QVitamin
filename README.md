## 🇧🇷 PORTUGUÊS

### 📋 Objetivo

Landing page desenvolvida para apresentação institucional da empresa **QVitamin** e do produto **Quality Mood**, criada como parte de um projeto de TCC do curso técnico de Administração.

O objetivo é apresentar a equipe, a marca e o produto de forma moderna, clara e persuasiva, utilizando boas práticas de Front-End, semântica HTML e responsividade.

### 🎨 Preview

Visite o projeto em produção:

**👉 [QVitamin - Live Demo](https://q-vitamin.vercel.app)**

### 🛠️ Tecnologias Utilizadas

- **HTML5** - Marcação semântica e estrutura
- **CSS3** - Estilização avançada com Flexbox, Grid, Animações e Gradientes
- **JavaScript** - Interatividade (vanilla JS, sem dependências)
- **Google Fonts** - Tipografia (Poppins)
- **Font Awesome** - Ícones vetoriais
- **Vercel** - Deploy e hospedagem

### ⭐ Funcionalidades

- ✅ Navegação fluida entre seções
- ✅ Apresentação visual do produto Quality Mood
- ✅ Destaque dos ingredientes naturais (Maracujá, Acerola, Camomila)
- ✅ Seção de benefícios e resultados
- ✅ Depoimentos de clientes
- ✅ Apresentação da equipe com links sociais
- ✅ Call-to-action para compra
- ✅ Botão "Voltar ao Topo" com scroll suave
- ✅ Links para redes sociais
- ✅ Design totalmente responsivo
- ✅ Animações suaves e transições

### 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/qvitamin.git
cd qvitamin
```

2. Abra o arquivo `index.html` no navegador ou use um servidor local:
```bash
# Com Python 3
python -m http.server 8000

# Com Node.js (http-server)
npx http-server
```

3. Acesse `http://localhost:8000` (ou a porta indicada)

## 🇬🇧 ENGLISH

### 📋 Purpose

Landing page developed for institutional presentation of **QVitamin** company and **Quality Mood** product, created as part of a Technical Administration course TCC (Final Project).

The objective is to present the team, brand and product in a modern, clear and persuasive way, using best Front-End practices, HTML semantics and responsiveness.

### 🎨 Preview

Visit the live project:

**👉 [QVitamin - Live Demo](https://q-vitamin.vercel.app)**

### 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Advanced styling with Flexbox, Grid, Animations and Gradients
- **JavaScript** - Interactivity (vanilla JS, no dependencies)
- **Google Fonts** - Typography (Poppins)
- **Font Awesome** - Vector icons
- **Vercel** - Deployment and hosting

### ⭐ Features

- ✅ Smooth navigation between sections
- ✅ Visual presentation of Quality Mood product
- ✅ Highlighting of natural ingredients (Passion Fruit, Acerola, Chamomile)
- ✅ Benefits and results section
- ✅ Customer testimonials
- ✅ Team presentation with social links
- ✅ Call-to-action for purchase
- ✅ "Back to Top" button with smooth scroll
- ✅ Social media links
- ✅ Fully responsive design
- ✅ Smooth animations and transitions
